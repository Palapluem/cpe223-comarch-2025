# CPE223 Computer Architecture 2025

Course workspace for CPE223 Computer Architecture, semester 1/2025. It contains lab work, lecture notes, project material, and quiz/exam preparation.

## Structure

```text
cpe223-comarch-2025/
├── labs/              # Lab exercises and implementation files
├── lectures/          # Lecture material and references
├── project/           # Course project work
├── quiz & exam prep/  # Review notes and practice material
├── .gitignore         # Local Codex/temp artifacts
└── README.md
```

## How To Use On Another Machine

1. Clone the repository.
2. Open the needed lab or project folder directly.
3. Use the toolchain required by each assignment, such as an assembler, simulator, C/C++ compiler, or HDL tool depending on the exercise.
4. Keep generated build outputs local unless they are required as final deliverables.

## Repository Policy

- Track source files, lab answers, diagrams, notes, and assignment documentation.
- Ignore `.codex/` and `.codex_tmp/` because they are local assistant/render scratch folders.
- Do not commit IDE-specific settings or build artifacts unless the course explicitly requires them.
